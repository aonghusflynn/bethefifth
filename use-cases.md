# Use Cases

The organiser will create a new game. A game will be a time and location that the match will be played. A match is an instance of a game.

The organiser will create a team. A team is a collection of players. Organisers can set a game to be recurring at set intervals. They can also assign players to a game. Players get notified that there is a match. Their responses are recorded.

If there are not enough players for a match, the organiser can put out a request for players to join the match. The organiser can accept or reject players who want to play in the match. An organiser can also rate players based on attributes such as sill level, punctiality and "soundness".

A player wants to find and join casual soccer matches nearby. They can browse open matches based on their location, see details like time, venue, and skill level, and join a match. After playing, the player can rate the match based on things like quality of the game, venue, and organisation.
